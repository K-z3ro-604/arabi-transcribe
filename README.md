# Arabic Transcription Hub

Build a responsive web application React and Tailwind CSS. The app MUST be strictly RTL (Right-to-Left) to support the Arabic language perfectly. Create a modern, professional dashboard with a sidebar containing these tabs: 'تفريغ الصوتيات', 'التدقيق والتشكيل', 'تنسيق وتصدير'.

For the first tab 'تفريغ الصوتيات' (Audio/Video Transcription): Create a beautiful Drag & Drop zone to upload audio and video files. Add a loading state with a progress bar. Below it, create a large, clean text area where the transcribed text will appear. Add a placeholder button 'ابدأ التفريغ' that simulates sending the file to an API and returning dummy Arabic text. Use Lucide-react for beautiful icons."
